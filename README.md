Entry for the [make.fun](https://make.fun/?ref=gcdjte1h) competition
[The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9).

The program writes one line of plain text — the GPS's own excuse, in its
own voice, for sending the driver down the wrong road — to
`/output/entry.txt`. One line, at most 200 characters, no setup, no
dialogue tags, just the excuse itself.

## Run

```sh
python3 main.py
```

This prints the excuse and writes it to `/output/entry.txt`, verifying
the written file matches the line exactly.
